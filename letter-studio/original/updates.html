WORKSHOP BETA 102 · RELEASE CANDIDATE

Clearer fixes.
More useful print files.

  • Errors now explain why a design is blocked and how to correct it. Calculable repairs show their exact changes and ask before applying them.
  • Hidden settings from a different decorative style no longer block the selected model.
  • Plate packing groups matching material and colour settings while preserving registered multicolour objects. Lightbox masks keep their own filament assignments.
  • The homepage includes an actual design and export walkthrough, followed by a render made from its exported STL.
  • Saved project files use a versioned format. Older supported designs are upgraded in memory; the original file is preserved. Unknown settings and files from newer apps show a recovery message.
  • Interface preferences no longer interrupt Save design.
  • Feature usage events help us understand which tools and downloads are useful, without including artwork or lettering.
  • Project descriptions now appear above neighbouring buttons on the welcome screen and project menus. Opening another description closes the previous one.
  • Canvas text now has an Apply text button. Pending words, fonts and spacing stay editable until you approve them. Apply changes includes pending text automatically.
  • Applying a canvas design checks the complete 3D parts before returning to Build. Failed checks keep your canvas open and preserve your previous model.
  • Pattern errors explain which setting to change, with actions to edit the pattern, increase spacing or use a solid face. Routine print notes are grouped separately.
  • Desk mounting adds an experimental Click & release choice with a 20 mm base, separate PLA-R3 horizontal locking key, rigid guides, wire passages and small fit-test parts. Use the samples before printing a full sign; physical fit and strength are not yet validated.
  • The four project types and the approved welcome screen are unchanged.
