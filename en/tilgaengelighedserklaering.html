Accessibility

Accessibility Statement

This statement describes the accessibility of FabLab Guides, including guide pages, material pages and interactive tools.

Last updated: 27 September 2026

Our goal

We want the site to be usable by as many people as possible, regardless of device, input method or ability.

We aim for ongoing improvements in line with WCAG 2.2 level AA.

Status

We cannot yet document that the entire site fully conforms to WCAG 2.2 level AA. The latest automated IBM Equal Access scan covered all 82 HTML pages and found 0 confirmed violations, 822 potential violations, 180 manual checks and 45 recommendations.

A result with 0 confirmed automated violations is not a complete WCAG approval. Potential findings and criteria that require human assessment still need manual review.

What already works

  • The shared navigation, skip links and image dialogs can be operated with a keyboard.
  • Guide carousels have visible, numbered steps and accessible names.
  • WeDo blocks can be added, moved, nested and deleted without dragging.
  • Key pages have been tested for reflow at 320 CSS pixels.

Known limitations

  • The entire site has not yet been reviewed with an actual screen reader, 200% text resizing or every system high contrast mode.
  • Complex editing and export workflows need further assistive technology testing. WeDo has not been tested with a physical Bluetooth hub.
  • Some older guides contain direction-based instructions and need editorial review.
  • External services, files and applications linked from the guides are not fully covered by our testing.

How we tested

On 27 September 2026, all 82 HTML pages were scanned with IBM Equal Access Accessibility Checker 4.0.34. We also use automated browser tests for keyboard operation, focus, dialogs, interactive tools and layouts at 320 and 1280 CSS pixels.

Feedback and contact

If you encounter an error or accessibility barrier, please contact johs.dahl@gmail.com. Include the page address, what you were trying to do, and the assistive technology or browser you used.

We prioritise problems that prevent access to content, navigation or functionality.
