Online tools

An overview of browser-based tools for laser cutting, 3D design, electronics and simulation. Selected for FabLab users who want to move quickly from idea to prototype.

10 new tools Design and simulation Ready for FabLab

What are online tools?

Online tools can automatically create files from your dimensions and settings or let you test electronics directly in the browser. They are a quick path to boxes, gears, 3D models and digital circuits without starting entirely from scratch.

Most tools are best for prototypes and quick iterations. Always check dimensions, joints and kerf in a test file before using expensive materials.

Boxes

Tools for boxes with finger joints, insert compartments and special shapes.

MakerCase

Simple generator for classic project boxes with 3D preview. Great for quick starts.

File type: SVG, DXF

Boxes.py

Very flexible open source generator with many box types and advanced settings.

File type: AI, DXF, GCODE, PDF, PLT, PS, SVG

Make a box

A simple and intuitive generator for boxes with symmetrical finger joints.

File type: PDF

Laser Cutter Box

Lightweight generator with live preview and different box types, including angled sides and dividers.

File type: DXF

Template Maker

Focus on cardboard and packaging templates. Good for folded constructions and quick mockups.

File type: PDF, SVG, DXF

Box Studio

New

Free box generator with kerf compensation, finger joints, 3D preview, hinged lids and optional internal dividers.

File type: SVG

Gears

Tools for involute gears, where function and geometry are important.

Involute Spur Gear Builder

Browser tool for gears, internal gears and rack-and-pinion with many parameters.

File type: DXF

Gear Designer

Quick generator for simple gears by adjusting module and number of teeth.

File type: DXF

GearDXF

New

Modern generator and simulator for spur gears, internal ring gears and racks, including backlash compensation.

File type: DXF, SVG, PDF

Flexible joints

Create flexible patterns in rigid sheet materials for curves, lids and enclosures.

Living Hinge Generator

New

Generates adjustable living-hinge patterns with straight, wave, hexagonal or cross-shaped cuts and an instant preview.

File type: SVG, DXF

Mazes

Generators for puzzles, game boards and creative mazes.

Laser-Cut Maze Designer

Generates laser-ready files for wooden mazes and mechanical maze projects.

File type: SVG

Maze Generator

Builds rectangular, triangular, circular and hexagonal mazes.

File type: PDF, SVG, PNG

CAD

Browser-based CAD tools for creating precise 2D and 3D models for prototypes, laser cutting and 3D printing.

Tinkercad

New

Free, beginner-friendly 3D modelling from Autodesk, where models are built by combining and adjusting simple shapes.

Good for: First CAD models and simple parts for 3D printing

JSCAD

New

Open source tool for parametric 2D and 3D models that are described with JavaScript and displayed directly in the browser.

Good for: Code-based and parametric CAD

SketchForge

New

Free, open source 3D editor with a simple workflow for shapes, combinations, adjustments and browser-based export.

Import and export: Including STL and SVG

Onshape

New

Professional parametric cloud CAD with parts, assemblies, version control and collaboration. The free plan is for non-commercial use and documents are public.

Good for: Advanced CAD and browser-based collaboration

3D design

Browser-based tools for creating models and preparing ideas for 3D printing.

MakerWorld MakerLab

New

A collection of browser-based design tools that help you create and customise models for 3D printing.

Output: Depends on the selected tool

Electronics and simulation

Build, program and test digital circuits virtually before assembling them physically.

Wokwi

New

Online simulator for Arduino, ESP32, STM32 and Raspberry Pi Pico, where code and electronics can be tested together.

Use: Microcontrollers, code and electronic components

CircuitVerse

New

Free open source simulator for digital logic circuits with logic gates, truth tables, timing diagrams and subcircuits.

Export: High-resolution images, including SVG

Other tools

Special generators that don't fit in the other categories.

Vector Ruler Generator

Create your own rulers with optional length and markings.

Jigsaw Puzzle Generator

Generates jigsaw puzzle patterns without manually drawing each piece.

File type: SVG

SVGnest

Automatic nesting, so parts are placed with minimal material waste.

File type: SVG (import/export)

Deepnest (app)

Desktop version with more advanced nesting functions.

File type: Depends on import format

Tips in practice
  • Always add kerf compensation if the tool supports it.
  • Check that units are mm before exporting.
  • Avoid duplicate lines in the finished file.
  • Save both the original and an export file for the machine.
